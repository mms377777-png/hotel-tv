# hotel-tv — приложение для телевизоров в номерах

Лёгкое приложение для Android TV (DEXP, Android TV 11) — домашний экран гостиницы «Сити Центр»
(Комсомольск-на-Амуре). Без сторонних библиотек, APK меньше 1 МБ.

## Что умеет (версия 1)

- **Главный экран** (можно сделать экраном по умолчанию вместо стандартного лаунчера):
  «Добро пожаловать!», имя гостя (если задано), название гостиницы, время и дата
  (часовой пояс Владивостока), погода в Комсомольске-на-Амуре (Open-Meteo, обновление раз в 30 минут;
  если интернета нет — строка просто пустая).
- **Плитки приложений**: ВК Видео, Rutube, YouTube, Кинопоиск, Wink, «ТВ-каналы».
  Если приложение не установлено — открывается Google Play или показывается подсказка.
- **«Проверить интернет»** для гостя: пинг, скорость загрузки и отдачи, цветной вердикт
  (зелёный ≥ 20 Мбит/с, жёлтый 5–20, красный < 5) и кнопка **«Сообщить администратору»**.
- **Автопроверка интернета** каждые 15 минут (пинг + ≈3 МБ загрузки), в том числе после включения ТВ.
- **Отчёты** — POST JSON на адрес REPORT_URL (веб-приложение Google Apps Script, которое пишет
  в таблицу и шлёт уведомление в Telegram; делается отдельно). В самом приложении нет никаких токенов.
  Если интернета нет, отчёты копятся (до 50) и уходят при следующей удачной отправке.
- **Служебное меню** для персонала (по PIN-коду).

Разрешения: только INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, RECEIVE_BOOT_COMPLETED.

## Где взять APK

Каждый push в `main` собирает APK через GitHub Actions:

- артефакт сборки `hotel-tv-apk` (страница запуска в Actions);
- релиз `latest`, файл `hotel-tv.apk`:
  `https://github.com/mms377777-png/hotel-tv/releases/download/latest/hotel-tv.apk`

> Внимание: репозиторий **приватный**, поэтому эта ссылка открывается только после входа в GitHub.
> Телевизор (Downloader) скачать по ней не сможет. Варианты: скачать APK на компьютер и выложить
> на Google Диск / свой сервер с публичной ссылкой, либо сделать репозиторий публичным
> (в коде нет секретов).

Сейчас собирается **debug-версия** (подписана debug-ключом). Подпись релизным ключом
(ключ в GitHub Secrets) будет настроена позже. Debug-ключ сборок хранится в кэше Actions;
если кэш пропадёт (не было сборок больше 7 дней), новая версия не встанет поверх старой —
тогда старую версию нужно удалить и поставить заново (настройки персонала при этом сбросятся).

## Установка на телевизор (для персонала)

1. На ТВ откройте Google Play, найдите и установите приложение **Downloader** (AFTVnews).
2. Разрешите Downloader устанавливать приложения: *Настройки → Приложения → Специальный доступ →
   Установка неизвестных приложений → Downloader → Разрешить* (на DEXP пункт может называться
   «Неизвестные источники»).
3. В Downloader введите прямую ссылку на `hotel-tv.apk` (см. выше) → «Go» → «Установить».
4. После установки файл APK в Downloader можно удалить («Delete») — места на ТВ мало.

Обновление — так же: скачать новый APK и установить поверх.

## Как сделать главным экраном

1. Нажмите на пульте кнопку **Домой (Home)**.
2. Если появится вопрос «Выберите приложение для главного экрана» — выберите **«Сити Центр ТВ»**
   и **«Всегда»**.
3. Если вопрос не появился: *Настройки → Приложения → Приложения по умолчанию → Главный экран*
   (на некоторых ТВ — *Настройки → Приложения → Все приложения → Домашний экран*) → «Сити Центр ТВ».
4. На части прошивок Android TV выбор другого главного экрана скрыт. Тогда приложение
   просто запускается из списка приложений; проверка «Главный экран по умолчанию: да/нет»
   видна в служебном меню.

Когда приложение — главный экран, кнопка «Назад» на нём ничего не делает.

## Служебное меню

- Открыть: кнопка **MENU** на пульте или **долгое нажатие ОК** на строке с названием гостиницы
  (стрелками навести на неё рамку и удерживать центральную кнопку).
- PIN по умолчанию: **0000**. Сразу поменяйте его в меню (поле «Новый PIN»).
- Поля: номер комнаты, название гостиницы, имя гостя (пусто — строка не показывается),
  REPORT_URL, адреса проверки скорости (download / upload / ping). После правки — «Сохранить».
- Информация: модель, версия Android, свободная память, IP, тип подключения, сеть и сигнал Wi‑Fi,
  версия приложения, сколько отчётов в очереди, результат последней автопроверки.
- Кнопки: «Полная проверка интернета» (без отправки отчёта), «Автопроверка сейчас (с отчётом)» —
  удобно проверить, что REPORT_URL работает, «Настройки Android».

Имя Wi‑Fi сети Android 11 отдаёт только приложениям с доступом к геолокации, которого у нас нет,
поэтому `wifi_ssid` обычно будет `null`; уровень сигнала (`wifi_rssi`) передаётся.

## Настройки по умолчанию (`app/src/main/java/ru/hotelkms/tv/Config.kt`)

| Поле | По умолчанию |
|---|---|
| Название гостиницы | `Сити Центр` |
| Имя гостя | пусто |
| PIN | `0000` |
| REPORT_URL | пусто → отчёты только в журнал (logcat) |
| Download URL | `https://speed.cloudflare.com/__down?bytes=25000000` |
| Upload URL | `https://speed.cloudflare.com/__up` |
| Ping URL | `https://speed.cloudflare.com/__down?bytes=0` |
| Пороги вердикта | зелёный ≥ 20 Мбит/с, жёлтый ≥ 5, красный < 5 |
| Полная проверка | загрузка до 25 МБ / 10 с, отдача 4 МБ / до 10 с, пинг — медиана 6 запросов |
| Автопроверка | каждые 15 мин (первая — через 2 мин после запуска): пинг + до 3 МБ |
| Погода | Open-Meteo, 50.55 / 137.01, Asia/Vladivostok, раз в 30 мин |

### Формат отчёта (POST, `application/json`)

```json
{
  "hotel": "Сити Центр",
  "room": "205",
  "type": "auto | guest | guest_complaint",
  "ping_ms": 38,
  "down_mbps": 45.2,
  "up_mbps": 18.7,
  "wifi_ssid": null,
  "wifi_rssi": -61,
  "app_version": "1.0.12",
  "timestamp": "2026-10-31T21:15:00+10:00"
}
```

`auto` — автопроверка (без отдачи, `up_mbps` = null); `guest` — гость нажал «Проверить интернет»;
`guest_complaint` — гость нажал «Сообщить администратору». Неизмеренные значения — `null`.
Ответ 2xx или 3xx считается успешным (Apps Script отвечает 302 — это нормально).

## Пакеты приложений — ПРОВЕРИТЬ НА РЕАЛЬНОМ ТВ

Плитка пробует пакеты по порядку. Если какой-то не подходит — узнать точное имя пакета
(например, в Google Play в адресе страницы `id=...`) и поправить `Config.kt` **и** блок `<queries>`
в `AndroidManifest.xml`.

| Плитка | Пакеты (по порядку) |
|---|---|
| ВК Видео | `com.vk.vkvideo`, `com.vk.tv` |
| Rutube | `ru.rutube.app` |
| YouTube | `com.google.android.youtube.tv` |
| Кинопоиск | `ru.kinopoisk`, `ru.kinopoisk.tv` |
| Wink | `ru.rt.video.app.tv`, `ru.rt.video.app.mobile` |
| ТВ-каналы | `com.google.android.tv`, `com.android.tv`, затем открытие списка каналов (`TvContract`), затем системные настройки |

Для «ТВ-каналов» на DEXP может стоять своё приложение эфирного ТВ — его пакет нужно найти и добавить.
